# SIO-K9 v0.6.2 — Drogas dinâmicas / sem mídias

Base: v0.6.1.

Em um único BOU, Sintéticos e Outros podem receber quantas linhas forem necessárias. Exemplo: Dry + Haxixe + Ice no campo Outros, e LSD + Ecstasy em Sintéticos. O fechamento mensal agrupa nomes iguais e soma os pesos de todos os BOUs.

O banco continua sendo `canil_mga_db_v21`, portanto os registros anteriores permanecem disponíveis. O módulo de mídias foi retirado da interface conforme solicitado.
